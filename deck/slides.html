Ergonomic risk is assessed with a clipboard, once, by one person.

How an assessment happens today

  1. WatchAn OSH manager stands beside one station for about 1 h a dayteam estimate.
  2. Score by eyeThey fill in a paper REBA or RULA checklist, posture by posture.
  3. File monthlyThe sheets are typed into a monthly report — about 8 h of desk work a monthteam estimate.

Why that is not enough

Subjective

Two assessors, two scores. The number depends on who held the clipboard.

Sampled

The risky posture happens in the 95 %team estimate of the shift nobody watches.

No history

Nothing to show the insurer, the auditor or the worker when they ask what changed.

One system answers all three: continuous evidence of control at every station, without adding headcount.

Pose to score in four deterministic steps.

1Find the pose

yolov8m_poseR3 returns 17 COCO keypoints for each person in every frame.

Target: ≥ 25 FPS at 1080p per streamteam estimate

2Measure the angles

Plain geometry, no learning: trunk flexion, neck flexion, upper-arm elevation, lower-arm angle, knee flexion.

Trunk twist from the shoulder-to-hip width ratio.

3Look up the score

REBA tables (Hignett & McAtamney 2000)R10 and RULA tablesR11.

Load and coupling are set per station at calibration.

4Score over time

Activity score: static posture > 1 min, repetition > 4/min, rapid changeR10.

Output: events with timestamps.

LineSafe · ASUS UGen AI League · Stage I6 / 18

The live path is a rule engine; the LLM only writes the report.

Live path — every frame

pose→angles→tables→alert
  • Deterministic. The same posture always gives the same score.
  • Auditable. Every score names the angle that caused it.
  • Fast. Table lookups keep up with the camera; no language model in the loop.

Report path — weekly

events→Qwen2.5-1.5B→summary
  • Same device. Qwen2.5-1.5B-Instruct on the UGen300: 7.35 tok/s, 2,048-token contextR4.
  • Plain language. Turns the week’s event table into a summary in the plant’s language.
  • Off the live path. 30–60 s per reportteam estimate; scoring never depends on it.

REBA is a lookup table. An LLM would be slower and could be wrong; a table cannot.

Known limits, stated plainly

  • Wrist flexion: COCO-17 has no hand points. Run hand_landmark_lite on a wrist crop, or use a station default.
  • Load and coupling: not visible to a camera; set per station at calibration.
  • 2D foreshortening: a camera placement guideline, checked by the κ study (slide 13).
